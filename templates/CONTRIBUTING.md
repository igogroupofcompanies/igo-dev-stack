# Contributing
- Branch: `feat/…`, `fix/…`, `chore/…`. Commits: Conventional Commits.
- PR checklist: tests pass · `CHANGELOG.md` updated · docs updated · no secrets · security checklist (`docs/security/SECURITY_POLICY.md`) ticked.
- AI-authored PRs follow `AGENTS.md` and must include a `HANDOFF.md` entry.
